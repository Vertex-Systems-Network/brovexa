# M04 WEB-029 — Asynchronous live admission cancellation fence

Development checkpoint (2026-10-16), staged for M04 GitHub branch.

- An injected permit loader, DNS resolver, M02 admission provider or storage-policy loader can hang independently of the HTTP timeout. WEB-029 places bounded awaits on each stage using the approved request timeout.
- Each stage immediately rejects when worker cancellation is requested, never calls its adapter when already cancelled, and ignores late resolutions or rejections after the fence trips.
- This is a *race*, not an ability to terminate third-party callback work or undo an already-committed database write. Callers must not advance to network or persistence after a rejection.
- WEB-030 maps bounded-stage timeout to the canonical worker RetryableWorkError rather than an unclassified permanent work error; cancellation remains cancelled.
- Added isolated native Vitest and offline regression candidates. They were **not executed in this batch**, following the owner's direction to defer checks until full M04 completion.
- No deployment, automatic live worker registration, remote request, or main/PR merge.
